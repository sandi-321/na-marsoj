# Na MarsOJ

MarsOJ 的油猴脚本，提供作业状态跳转、颜色标识、首页作业优化、公告替换和自动更新等功能。

## 安装

1. 安装 Tampermonkey 扩展。
2. 点击以下链接安装脚本：
   - [直接安装](https://raw.githubusercontent.com/sandi-321/na-marsoj/main/dist/na-marsoj.user.js)
   - 备用链接（jsDelivr）：[安装](https://cdn.jsdelivr.net/gh/sandi-321/na-marsoj@main/dist/na-marsoj.user.js)
3. 访问 marsoj.cn，导航栏出现「Na MarsOJ 设置」即安装成功。

## 功能

- 作业状态跳转：作业列表中的状态文字变为链接，点击后跳转到对应的提交记录页面。
- 状态颜色标识：部分得分显示橙色，未通过显示红色。
- 首页作业优化：将首页的待完成作业替换为最新作业，显示截止时间和提交进度。
- 公告替换：将首页的「暂无公告」替换为脚本的公告内容，包含版本更新说明和仓库链接。
- 自动更新检测：页面刷新时静默检查新版本（30分钟内最多一次），发现新版本后在设置面板的更新分类中显示更新按钮。支持手动检查更新，同时从多个源获取版本信息，取最高版本。

## 设置

设置面板提供以下选项：
- 提示框自动关闭时间
- “学习”按钮跳转地址
- 作业状态重定向开关
- 部分得分颜色优化开关
- 未通过颜色优化开关
- 首页待完成作业优化开关
- 脚本更新检查

支持恢复默认设置。
